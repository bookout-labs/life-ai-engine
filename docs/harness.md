# Agent harness

T3 creates one worktree per thread through t3.json and installs dependencies. Hooks provide context, block raw save commands and protect generated instructions. .agents/rules.ts owns routed rules; rules.ts --write regenerates AGENTS.md. CLAUDE.md points to that generated view. Codex and Claude hook configuration uses repository-relative paths.

Session start fetches origin/main and reports divergence without changing files. Personal work uses Neon pages and R2 files. Read members and personal pages for current context instead of embedding household facts in engine procedures.

Use the installed task skills where applicable. Documents and procedures should describe behavior independently of the agent provider. Code changes run npm run check. Use save.ts from the thread branch when saving is authorized. The gate runs main's copy, chooses a reviewer from another family, and records its verdict in CI.
