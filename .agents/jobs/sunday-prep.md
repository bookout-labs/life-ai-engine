# Weekly preparation

Follow the scheduled preparation in the sunday skill. Run `node .agents/scripts/weekly.ts` before composing the dashboard. For a different target week, pass its first date as YYYY-MM-DD. Use the returned record collections and report empty, unknown and unavailable data explicitly. Read timing, recipients, communication authorization and personal preferences from private pages or settings. Write weekly notes through pages.ts. Send only when explicitly authorized. Report unavailable sources privately.
